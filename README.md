# pitch training♬

吹奏楽・合唱における「音程感」を、楽しく・分かりやすく・継続して身につけることを目指したWebアプリです。

中学3年生の卒業研究として、吹奏楽部での日常的な練習から感じた課題をもとに開発しています。

---

## 現在の構成

現在の `index.html` は、**研究発表用の参加型クイズと pitch training♬ 本体を一体化**しています。

1. オープニング
2. 第1問の説明
3. 基準音・A・Bを試聴して挙手
4. 正解発表＋花吹雪
5. 第2問の説明
6. 基準音・A・Bを試聴して挙手
7. 正解発表＋花吹雪
8. 研究の導入
9. そのまま `pitch training♬` 本体へ移動

別ページへの移動は不要です。

## 発表用オープニングクイズ

### 第1問「同じ『ド』はどっち？」

基準音の「ド」を聴いたあと、

- A：基準音と同じ「ド」
- B：「ミ」

を再生し、どちらが基準音と同じ高さかを挙手で答えます。

### 第2問「今度も同じ『ド』はどっち？」

基準音の「ド」を聴いたあと、

- A：基準音より20セント高い「ド」
- B：基準音と同じピッチの「ド」

を再生し、どちらが基準音と同じピッチかを答えます。

第2問では、同じ音名でもわずかなピッチの違いがあることを体験してもらい、そのまま研究テーマへつなげます。

### 発表用の工夫

- 16:9を意識したプレゼン画面
- 画面切り替えアニメーション
- 正解画面で花吹雪
- Chromebookでも動作しやすいよう、花吹雪は外部ライブラリに依存しない実装
- 右矢印キー / Space：次へ
- 左矢印キー：前へ
- クイズ音は聞き取りやすいよう高めの音域・大きめの音量に調整

## pitch training♬ 本体

`pitch training♬` は、基準音を聴いたあとに自分で音を出し、マイクで音程を測定して、基準音とのズレをリアルタイムに確認できるWebアプリです。

### 主な機能

- 1回10問のトレーニング
- 基準音を聴いたあと3秒間演奏
- マイク入力から音程を解析
- 基準音とのズレをセント（cent）で表示
- 「少し高い」「少し低い」などの視覚的フィードバック
- ゲージ表示の平滑化
- Excellent / Great / Good / Almost の4段階評価
- 練習履歴を端末内に保存
- Google Apps Script経由でGoogleスプレッドシートへ結果を送信

---

## 練習レベル

### Lv.1：ユニゾン
基準音と同じ高さの音を出す基本練習です。

### Lv.2：パワーコード
根音（基準音）を鳴らし続けた状態で、完全5度・完全4度の響きを合わせます。

### Lv.3：純正律ハーモニー
根音（基準音）を聴きながら、純正律の長3度を合わせます。

Lv.1〜3にはそれぞれ「？」ボタンがあり、練習内容の説明を確認できます。

---

## 自由練習モード

根音（基準音）とハモる音程を自分で選び、1回ずつテンポよく練習できます。

選択できる音程：

- 完全5度
- 完全4度
- 長3度（純正律）
- 短3度（純正律）

自由練習では10問制ではなく、

**音を選択 → 1回練習 → 結果確認 → 次の音を選択**

という流れで利用できます。

## 公開方法

GitHubリポジトリのルートに、現在の一体型ファイルを

`index.html`

として配置します。

GitHubの

`Settings → Pages`

から、

- Source：`Deploy from a branch`
- Branch：`main`

を設定します。

`https://ユーザー名.github.io/リポジトリ名/`

## 開発の考え方

この研究では、単に「音程を測るアプリを作る」ことだけを目的としていません。

- 音程練習を楽しく続けられるか
- 失敗してももう一度試したくなるか
- 自分の音程の変化を確認できるか
- 実際に使った人の意見をもとに改善できるか

といったUX（ユーザー体験）も重視しています。

また、生成AIを完成品を一度で作らせるためではなく、

**課題発見 → AIへの相談 → 実装 → 動作確認 → 問題発見 → 改善**

という開発サイクルの中で活用しています。
